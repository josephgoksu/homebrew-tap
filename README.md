# josephgoksu/tap

```bash
brew tap josephgoksu/tap
```

| Install | What |
|---|---|
| `brew install --cask josephgoksu/tap/strain` | [Strain](https://github.com/josephgoksu/strain): menu bar app that names what is straining your Mac |
| `brew install josephgoksu/tap/taskwing` | TaskWing CLI |
| `brew install --cask josephgoksu/tap/metagrab` | [metagrab](https://github.com/josephgoksu/metagrab): link previews from any URL (CLI and HTTP API) |

The Strain cask is updated by Strain's release workflow on every tagged release. The metagrab cask is updated by metagrab's release workflow when the `HOMEBREW_TAP_TOKEN` secret is set there.
