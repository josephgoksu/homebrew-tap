# josephgoksu/tap

```bash
brew tap josephgoksu/tap
```

| Install | What |
|---|---|
| `brew install --cask josephgoksu/tap/halo` | [Halo](https://halo.reaktif.io/): launcher, cleaner, screenshots and system monitor in the notch (needs a license key) |
| `brew install josephgoksu/tap/taskwing` | TaskWing CLI |
| `brew install --cask josephgoksu/tap/metagrab` | [metagrab](https://github.com/josephgoksu/metagrab): link previews from any URL (CLI and HTTP API) |

The Halo cask is written by Halo's release workflow on every tagged release; Strain was renamed Halo; the `strain` cask is disabled and points to `halo`. The metagrab cask is updated by metagrab's release workflow when the `HOMEBREW_TAP_TOKEN` secret is set there.
