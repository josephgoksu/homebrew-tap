# josephgoksu/tap

```bash
brew tap josephgoksu/tap
```

| Install | What |
|---|---|
| `brew install --cask josephgoksu/tap/strain` | [Strain](https://github.com/josephgoksu/strain): menu bar app that names what is straining your Mac |
| `brew install josephgoksu/tap/taskwing` | TaskWing CLI |

The Strain cask is updated by Strain's release workflow on every tagged release.
